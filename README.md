# ระบบวิเคราะห์ต้นทุนอาหาร & กระดานสเปกวัตถุดิบครัวแสนสุข (Kitchen Prep Board)

ระบบบริหารต้นทุนอาหารและกระดานสเปกเตรียมวัตถุดิบหน้าร้านสำหรับร้าน **ครัวแสนสุข** (โทร 080-143-2563)  
ออกแบบตามหลักการ **F&B Cost Controller**, **Market Price Analyst**, และ **Kitchen Management Expert**  
ถอดสูตรและสเปกวัตถุดิบจากภาพถ่ายเมนูโฆษณา 19 ไฟล์รูป พร้อมระบบเชื่อมต่อ **Multi-Device Real-Time Sync** สำหรับใช้งานบนโทรศัพท์มือถือหลายเครื่องพร้อมกัน

---

## 🌟 จุดเด่นของระบบ (Key Features)

1. **รองรับการใช้งานบนมือถือทุกรุ่น (Mobile-First Responsive)**:
   - ออกแบบ UI สำหรับหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์
   - แถบเมนูด้านล่าง (Sticky Bottom Navigation) สะดวกต่อการสัมผัสด้วยมือเดียว
   - การ์ดเตรียมอาหารขนาดใหญ่อ่านง่าย สบายตาสำหรับพ่อครัว

2. **เชื่อมต่อและซิงค์ข้อมูลร่วมกันแบบเรียลไทม์ (Multi-Device Live Sync via WebSockets)**:
   - ทีมงานสามารถเปิดใช้งานจากมือถือคนละเครื่องได้พร้อมกัน
   - เมื่อใครคนหนึ่งปรับราคาวัตถุดิบที่ตลาดสด หรือแก้สเปกที่หน้าร้าน **ทุกเครื่องจะอัปเดตตรงกันทันทีแบบ Real-Time ภายในเสี้ยววินาที**
   - มีปุ่มสแกน **QR Code** หรือแชร์ลิงก์ส่งเข้ากลุ่ม LINE ได้ทันที

3. **ควบคุมโครงสร้างต้นทุนเข้มงวด**:
   - ควบคุม **Total Food Cost $\le$ 40%**
   - รักษา **Gross Profit Margin $\ge$ 60%**
   - ต้นทุนวัตถุดิบหลัก-รองเป้าหมาย **35% - 40%** (เน้นเนื้อสัตว์แน่น จานใหญ่ ซื้อใจลูกค้า)
   - ไม่แสดงเครื่องปรุงย่อย (<1%) บนกระดานครัว เพื่อความรวดเร็วในการปรุง

4. **กระดานเตรียมครัว (Kitchen Prep Board)**:
   - จำกัด 3-5 รายการที่ต้องเตรียม
   - สื่อสารชัดเจนด้วย 3 กริยา: ⚖️ **ชั่ง (กรัม)**, 🔢 **นับชิ้น (ตัว/ฟอง)**, 🧪 **ตวง (มล.)**
   - สลับดูแบบการ์ด หรือตารางพิมพ์สำหรับติดผนังครัว (Print-Ready)

5. **ระบบจัดการราคาตลาดรอบ 7 วัน (7-Day Market Sync)**:
   - จำลองการปรับเปลี่ยนราคาตลาดสดทุก 7 วัน
   - แสดงสัญลักษณ์เตือนความเคลื่อนไหว: 🔺 สีแดง (ราคาขึ้น) และ 🔻 สีเขียว (ราคาลง)
   - สลับใช้งานระหว่าง "ราคาตลาดอัตโนมัติ" และ "ราคาตั้งเองตามพื้นที่ (Custom Price)" ได้อิสระ
